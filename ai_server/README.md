# BGTI LMS — ميزة التوليد الآلي بالذكاء الاصطناعي (AI Auto-Generation)
**دورة: اللغة الإنجليزية الفنية والمصطلحات المهنية (Technical English)**

تتيح هذه الميزة للمدرب رفع ملفات العروض التقديمية (**PowerPoint `.pptx`**) أو المستندات التدريبية (**PDF `.pdf`**)، ليقوم الذكاء الاصطناعي بتحليل النص كاملاً وتوليد مكونات الأسبوع الأربعة تلقائياً وتوزيعها في واجهة LMS:

1. **المحاضرات والشروحات المرئية (Lecture Overview):** عنوان المحاضرة، المدة، والملخص الشامل.
2. **المذكرات والملخصات الدراسية (Glossary & Notes):** قاموس مصطلحات فنية إنجليزية مترجمة للعربية مع الشرح المختصر.
3. **الاختبارات التفاعلية (Quiz & Questions):** اختبار أسبوعي إلكتروني (10 درجات، 15 دقيقة) بأسئلة اختيار من متعدد (MCQ) مع تحديد الإجابات الصحيحة وتصحيحها آلياً.
4. **الواجبات والتكليفات الأسبوعية (Assignments):** تكليف أسبوعي تطبيقي مع التعليمات والأسئلة وورقة العمل.

## 🚀 طريقة التشغيل السريع على جهازك المحلي (Localhost)

### الخطوة 1: تثبيت الحزم المطلوبة (تم تثبيتها بالفعل)
```bash
python -m pip install python-pptx pypdf pdfplumber google-generativeai flask flask-cors
```

### الخطوة 2: إعداد مفتاح Gemini API
احصل على مفتاح مجاني من [Google AI Studio](https://aistudio.google.com/app/apikey)، ثم اختر إحدى الطريقتين:

- **الطريقة (أ) ملف `.env` (موصى بها):**
  انسخ ملف `.env.example` إلى `.env` في مجلد `ai_server` وضع مفتاحك:
  ```env
  GEMINI_API_KEY=AIzaSyYourActualKeyHere
  ```

- **الطريقة (ب) عبر سطر الأوامر:**
  ```cmd
  set GEMINI_API_KEY=AIzaSyYourActualKeyHere
  ```

> **ملاحظة:** حتى بدون مفتاح API، يعمل السيرفر بنظام **Smart Text Fallback** بحيث يستخرج النص الحقيقي من ملفاتك ويولّد عناصر الأسبوع مباشرة ليتيح لك تجربة الواجهة والتأكد من عملها فوراً!

### الخطوة 3: تشغيل الخادم
- **في نظام Windows:** اضغط نقراً مزدوجاً على الملف:
  ```
  ai_server\start_server.bat
  ```
- **أو من سطر الأوامر (PowerShell / CMD):**
  ```bash
  cd c:\Users\USER\Downloads\attendance-app\ai_server
  python server.py
  ```

سيعمل الخادم على العنوان:
```
http://localhost:5005
```

### الخطوة 4: فتح المنصة واستخدام الميزة
1. افتح صفحة المنصة [`index.html`](../index.html) في متصفحك.
2. ادخل كمدرب وانتقل إلى تبويب **إدارة المقرر (LMS)**.
3. اختر الأسبوع التدريبي واضغط على الزر البنفسجي: **✨ توليد بالذكاء الاصطناعي**.
4. اسحب أو اختر ملف الـ PPTX أو PDF واضغط **✨ ابدأ التوليد بالذكاء الاصطناعي**.
5. راجع المعاينة المباشرة للمكونات الأربعة، ثم اضغط **💾 حفظ ونشر المحتوى الكامل للأسبوع**.
